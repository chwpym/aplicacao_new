# Gerenciador de Catálogo de Peças (DMA)

Uma plataforma centralizada para profissionais de autopeças consultarem e compararem aplicações de múltiplos fabricantes em tempo real.

![Preview do Sistema](https://img.shields.io/badge/Status-Operacional-brightgreen)
![Tech Stack](https://img.shields.io/badge/Stack-FastAPI%20|%20React%20|%20Tailwind-blue)

## 🎯 O que é o projeto?

O sistema resolve o problema de fragmentação de dados no mercado de reposição automotiva. Em vez de abrir 10 abas de sites diferentes, o usuário digita um código e recebe todas as aplicações unificadas, formatadas e prontas para cópia.

## 🚀 Início Rápido

Para rodar o projeto localmente:
1.  Abra a pasta raiz no seu explorador de arquivos.
2.  **Dê um duplo clique no arquivo `start.bat`**.
3.  O sistema abrirá automaticamente o servidor de dados (Backend) e a interface (Frontend).

## 💎 Diferenciais Técnicos

-   **Robô Inteligente (Scraping)**: Capaz de navegar em sites de marcas, ler tabelas complexas e extrair fotos oficiais e referências originais.
-   **Busca Híbrida**: Combina APIs modernas (GraphQL/REST) com extração de dados clássica (HTML).
-   **Copia Inteligente**: Diferentes modos de cópia (Completa, Intermediária e Agrupada) que removem duplicatas e organizam os dados para colagem em sistemas de vendas.
-   **Galeria Dinâmica**: Visualização instantânea de fotos da peça para evitar erros de identificação.
